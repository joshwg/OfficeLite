# Keyboard and mouse reference

Every key binding in ExcelLite and WordLite, listed by context, with the
differences from Excel and Word:

- [Windows and Linux](./KEYBOARD-WINDOWS.md) (Ctrl, Alt)
- [macOS](./KEYBOARD-MAC.md) (Cmd, Option, Mac key names)

The web version uses the keys of the system the browser runs on: Ctrl
on Windows and Linux, Cmd on a Mac. The browser keeps some keys for itself
(closing the tab, new windows and tabs), so Ctrl+W / Cmd+W and Ctrl+N /
Cmd+N may act on the browser instead of the document.
